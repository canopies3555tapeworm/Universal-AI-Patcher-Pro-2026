## FAQ

### Is OmniPatch safe to use on my computer?

Yes, OmniPatch is designed to be safe. It only modifies specific configuration files for target applications, creates system restore points, and does not alter core operating system files or install any background services.

### Which AI applications are currently supported?

OmniPatch supports patching for ChatGPT, Claude, Perplexity, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI. Support for additional tools is added regularly.

### How often is OmniPatch updated?

The tool is updated frequently, typically within a few days after major updates to any supported AI application, to maintain compatibility and patch effectiveness.

### Does OmniPatch work on both Windows 10 and 11?

Yes, OmniPatch is compatible with Windows 10 (version 1903 and later) and Windows 11. It is optimized for the latest operating system versions.

### Why does my anticomponent flag OmniPatch?

Some security software may flag patching tools due to their behavior of modifying application files. This is a generic alert. OmniPatch is open-source and contains no malicious code; you can verify this by inspecting the source code.

### Can I uninstall the patches if needed?

Yes, OmniPatch includes a 'Restore Backups' function that reverts all changes made by the patcher, returning your applications to their original, unpatched state.

### What is the difference between the free and future paid versions?

The core patching functionality is and will remain free. A potential future 'Pro' version might offer automated updates, priority support, or patching for a wider range of niche tools.

### Do I need to keep OmniPatch installed to use the patched features?

No. Once patches are applied successfully, they persist in the target applications. You can close or even delete OmniPatch, and the premium features will remain active until the patched application itself is updated.
